# Functional acceptance accounting (AOS-058)

This is a separate 62-point **engineering functionality** subledger beneath the eight frozen MVP-F criteria. It does **not** replace or reweight the original 100-point product acceptance baseline. The previous headline remains 23/100 until an entire independently accepted gate passes. A documented completed subcriterion may be counted here only if an actually executed acceptance suite and its GitHub CI evidence exist. Mock-only tests, unfinished UI, human-play claims and unverifiable external integrations cannot earn a point.

Run `node scripts/product-progress.mjs --json` or `npm run progress`. Review `docs/functional-acceptance.json` for the fixed 24 accepted/pending subcriteria and exact evidence paths. Verification references are the reviewed AOS-056/AOS-057 CI runs; the ledger can be revised only for a justified acceptance-status change accompanied by current proof, not by moving the denominator.

Commercial release remains **not accepted** without newsroom fact-checking, ten consenting human players, accessibility signoff, and an approved production deployment/recovery exercise. This indicator counts completed engineering capabilities only; it does not claim those external obligations have been fulfilled.
